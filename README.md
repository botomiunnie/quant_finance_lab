# 미국 은행 수익성·리스크 분석

FDIC 은행 재무 데이터로 자산 규모에 따라 수익성이 얼마나 다른지 살펴봤습니다.
자산 규모별 ROA·ROE·순이자마진을 비교하고, 예대율과 자본비율의 관계도 확인했습니다.

## 분석하면서 확인한 점

ROA를 확인하다 보니 FDS BANK가 503.05%로 다른 은행보다 유독 높았습니다.
이 은행 한 곳을 빼고 다시 계산하니 평균은 **1.30%에서 1.19%**로 내려갔지만,
중앙값은 소수 둘째 자리까지 **1.10%**로 같았습니다.
그래서 자산 규모별 수익성을 비교할 때는 중앙값을 사용했습니다.

예대율과 자본비율은 스피어만 순위상관으로 비교했습니다.
자본비율이 0으로 기록된 경우는 그 의미를 확인하기 어려워,
0을 포함했을 때와 제외했을 때의 결과를 함께 계산했습니다.

## 실행 방법

```bash
python -m pip install pandas matplotlib scipy
```

`fdic_2025_q3.csv`를 노트북과 같은 폴더에 놓고,
